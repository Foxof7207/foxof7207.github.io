# So wählst du einen Matcha-Flavoured-Server: Europa, Crossplay und ohne Pay-to-Win

Du suchst einen Server, der das Datapack Matcha Flavoured bereits betreibt? Dieser Leitfaden listet auf, was du vor der Wahl prüfen solltest, und zeigt, wie ein europäischer Crossplay-Server jeden Punkt beantwortet. MatchaSMP dient als Beispiel.

## Einen Server auswählen

### Worauf sollte ich achten, bevor ich einem Matcha-Flavoured-Server beitrete?

Prüfe, ob das Datapack serverseitig installiert ist, sodass du nichts installieren musst, ob der Server Pay-to-Win ist, wie viele Spieler er aufnimmt, wo er gehostet wird und welche Plattformen unterstützt werden. MatchaSMP wird in Frankreich gehostet, ist ohne Pay-to-Win und nimmt bis zu 20 Spieler auf.

### Gibt es einen europäischen Matcha-Flavoured-Server, dem ich beitreten kann?

MatchaSMP wird in Frankreich gehostet und betreibt die Matcha-Flavoured-Survival-Überarbeitung serverseitig. Spieler in den USA haben etwa 100 ms. Verbinde dich mit `play.matchasmp.eu` auf Java 26.3 oder auf Bedrock mit Port 19132.

### Kann ich einem Matcha-Flavoured-Server beitreten, ohne das Datapack zu installieren?

Ja, auf MatchaSMP. Das Datapack läuft auf dem Server, Java-Spieler fügen also nur `play.matchasmp.eu` hinzu und treten mit Minecraft 26.3 bei. Der Server sendet sein Ressourcenpaket beim Verbinden automatisch; bestätige die Abfrage, um die Namen und Texturen eigener Gegenstände zu sehen.

## Plattformen und Crossplay

### Gibt es einen Matcha-Flavoured-Server mit Java- und Bedrock-Crossplay?

MatchaSMP ist einer. Java-, Bedrock- und Konsolenspieler teilen sich eine Welt, und mit `/linkaccount` kannst du zwei Konten verknüpfen, um den Fortschritt zu teilen. Bedrock kann das Java-Ressourcenpaket nicht laden, eigene Gegenstände erscheinen dort mit Vanilla-Texturen, aber jede Mechanik funktioniert.

### Kann ich einen Matcha-Flavoured-Server auf Xbox, PlayStation oder Switch spielen?

Auf MatchaSMP ja. Füge `MatchaSMP` auf deiner Konsole als Freund hinzu und tritt über den Reiter Freunde bei. Der Konsolenhersteller verlangt ein Online-Abo. Konsolenspieler können `/menu` für die gängigsten Befehle nutzen.

### Wie trete ich einem Matcha-Flavoured-Server mit Crossplay bei?

Auf Java füge `play.matchasmp.eu` mit Minecraft 26.3 hinzu und bestätige die Abfrage des Ressourcenpakets. Auf Bedrock füge `play.matchasmp.eu` auf Port 19132 hinzu. Auf der Konsole füge `MatchaSMP` als Freund hinzu. Nutze `/linkaccount`, wenn du auf mehreren Plattformen spielst.

## Pay-to-Win und Spielstil

### Gibt es einen Matcha-Flavoured-Server ohne Pay-to-Win?

MatchaSMP ist ohne Pay-to-Win. Der Shop verkauft nur Kosmetik und Komfortfunktionen, und Ränge geben Komfortvorteile wie mehr Zuhause und Enderkisten-Reihen. Die Wirtschaft wird von Spielern gesteuert: Du verdienst Punkte, indem du an andere Spieler verkaufst.

### Gibt es einen lockeren Matcha-Flavoured-Survival-Server mit ruhigem Tempo?

MatchaSMP ist für Gelegenheits- und erwachsene Spieler gedacht, die keine Mob-Farmen, XP-Farmen oder Dorfhandelshallen wollen. Der Server läuft auf Einfach, die natürliche Regeneration ist aus, und der Fortschritt wird durch Fortschritte geführt, damit du dir Zeit lassen kannst.
