# Expansion

Grow the world border so you can explore more terrain and discover new structures.

| Command | Description |
| :--- | :--- |
| `/borderplus collective <worldName>` | Open the expansion menu for the selected world. |

---

::: tip Default world size
The starting world is a 500×500 cube. Expand it by collecting items, spending XP, or using in-game money.
:::
