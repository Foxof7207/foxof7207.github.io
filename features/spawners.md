# Custom Spawners

An easy way to use spawners !

| Action | Tool | How to |
| :--- | :--- | :--- |
| **Mine it** | `Silk Touch pickaxe` | Pick up a villager into your inventory. |
| **Place** | `Spawner` | Place the spawner like a normal block. |
| **Collecting loot** | `Empty hand`| Click on the spawner. |
| **Fixing a mending tool** | `Holding the tool`| Click on the spawner. |


::: warning Bedrock issue
You cannot acces a spawner GUI if you are holding an item
:::
