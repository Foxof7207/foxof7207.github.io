# Expantions

Ranks are solely based on playtime, so there is *no* P2W.

| Ranks | How to get | Unlocked |
| :--- | :--- | :--- |
| `Newbie` | The default rank gifted to everyone. | `/spawn /back  /tpa  /suicide` |
| `Casual` | More than 1h of playtime. | Not yet Defined |
| `Lover` | More than 2h of playtime. | Not yet Defined |
| `Gatherer` | More than 5h of playtime. | Not yet Defined |
| `Farmer` | More than 1d of playtime. | Not yet Defined |
| `Miner` | More than 2d of playtime | Not yet Defined |
| `God` | More than 7d of playtime. | Not yet Defined |







---

::: tip Ranks purpose
Higher you rank is, more commands you will unlock. So keep playing to unleesh your powers !
:::
