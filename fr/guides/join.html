Comment rejoindre un serveur de survie Minecraft depuis Java, Bedrock ou console

Vous voulez jouer à la survie Minecraft avec des amis qui utilisent un autre appareil ? Ce guide explique comment les joueurs Java, Bedrock et console se connectent à un même serveur crossplay. MatchaSMP sert d'exemple.

9 réponsesWiki complet →

Adresses du serveur par plateforme

Quelle adresse et quel port utiliser pour rejoindre un serveur Minecraft depuis Bedrock ?

Sur MatchaSMP, les joueurs Bedrock utilisent l'adresse play.matchasmp.eu avec le port 19132. Sous Windows, Android, iPhone et iPad, le bouton Ajouter à Minecraft de la page du serveur ouvre le jeu avec le serveur déjà ajouté.

Quelle version de Minecraft Java faut-il pour rejoindre un serveur de survie ?

MatchaSMP exige Minecraft Java 26.3, les versions plus anciennes ne peuvent donc pas se connecter. Utilisez l'adresse play.matchasmp.eu : les joueurs Java, Bedrock et console partagent le même monde.

Comment rejoindre un serveur Minecraft depuis Xbox, PlayStation ou Switch ?

Ajoutez MatchaSMP comme ami sur votre console et rejoignez depuis l'onglet Amis. Le fabricant de votre console exige un abonnement en ligne pour jouer en ligne, vous en avez donc besoin pour vous connecter.

Comptes et accès

Puis-je rejoindre un serveur Minecraft avec un lanceur cracké ou hors ligne ?

Non. MatchaSMP fonctionne en mode en ligne : seuls les comptes Minecraft légitimes et payants peuvent rejoindre. Les lanceurs crackés et hors ligne ne peuvent pas se connecter.

Faut-il être sur une liste blanche pour rejoindre un serveur Minecraft ?

Pas sur MatchaSMP. Il n'y a pas de liste blanche : toute personne possédant un compte légitime peut rejoindre. Le serveur accueille jusqu'à 20 joueurs.

Pourquoi mon pseudo Bedrock commence-t-il par un tiret bas sur un serveur Java ?

Les pseudos Bedrock reçoivent un préfixe _ et les espaces deviennent des tirets bas, pour ne jamais entrer en conflit avec les pseudos Java. Le préfixe est le même sur le proxy et sur le serveur : vous gardez un seul pseudo partout.

Avant votre première session

Faut-il un pack de ressources pour jouer sur un serveur Minecraft avec des objets personnalisés ?

Sur Java, oui. MatchaSMP envoie automatiquement son pack de ressources quand vous rejoignez : acceptez simplement la demande. Sans lui, les objets personnalisés ressemblent à la version vanilla et certains ont des noms textuels bruts. Bedrock ne peut pas charger les packs Java : les joueurs Bedrock voient donc les textures vanilla, mais tout fonctionne quand même.

Quels mods puis-je utiliser sur un serveur de survie Minecraft ?

Les mods côté client comme les outils de performance, les minimaps, les shaders et le chat vocal sont autorisés sur MatchaSMP. Les mods de triche comme X-ray, freecam ou les clients modifiés ne le sont pas, et le serveur utilise un anti-triche.

Que faire en premier après avoir rejoint un serveur de survie ?

Ouvrez vos progrès avec L sur Java : la refonte de la survie les utilise comme guide pas à pas. Une fois que vous avez une base, définissez une maison avec /sethome base, et /spawn vous ramène au spawn à tout moment.
