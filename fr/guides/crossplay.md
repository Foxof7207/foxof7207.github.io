# Les joueurs Java et Bedrock peuvent-ils partager un même monde Minecraft ? Explications du crossplay

Le crossplay permet aux joueurs Minecraft sur Java, Bedrock, Xbox, PlayStation et Switch d'explorer ensemble le même monde. Ce guide explique comment cela fonctionne en pratique, de la liaison des comptes à ce que voit chaque plateforme. MatchaSMP sert d'exemple.

## Jouer ensemble entre plateformes

### Les joueurs Java et Bedrock peuvent-ils jouer dans le même monde Minecraft ?

Oui. Sur MatchaSMP, les joueurs Java, Bedrock, Xbox, PlayStation et Switch partagent un même monde. Java utilise `play.matchasmp.eu`, et Bedrock utilise la même adresse sur le port **19132**.

### Puis-je utiliser les mêmes commandes sur Bedrock et console que sur Java ?

Presque. Les joueurs Bedrock et console disposent de la plupart des commandes sous forme de boutons dans `/menu` : maisons, demandes de téléportation, coffre de l'End, commandes, échanges et messages privés. Les messages cliquables ne fonctionnent pas sur Bedrock, c'est une limitation de Bedrock.

### Puis-je utiliser le chat vocal sur un serveur crossplay si je joue sur console ?

Le chat vocal est facultatif. Les joueurs Java peuvent installer le mod Simple Voice Chat, mais Bedrock et console ne peuvent pas l'utiliser, il n'est donc jamais obligatoire pour jouer.

## Comptes et progression

### Comment lier un compte Java et un compte Bedrock pour partager la progression ?

Exécutez `/linkaccount` sur un compte et suivez les instructions pour le lier à l'autre. Une fois liés, les deux comptes partagent un seul profil de joueur. `/unlinkaccount` annule la liaison.

### Pourquoi mon pseudo Bedrock commence-t-il par un tiret bas ?

Les pseudos Bedrock reçoivent un préfixe `_` et les espaces deviennent des tirets bas. Cela évite les conflits avec les pseudos Java, et le préfixe est le même sur le proxy et sur le serveur : vous gardez un seul pseudo partout.

### Les joueurs Bedrock peuvent-ils voir les textures personnalisées du pack Java ?

Non. Bedrock ne peut pas charger les packs Java : les joueurs Bedrock voient les textures vanilla et parfois des clés brutes sur les objets personnalisés. Tout fonctionne quand même, mais l'apparence personnalisée n'apparaît que sur Java.

## Mods et fair-play

### Quels mods sont autorisés sur un serveur Minecraft crossplay ?

Les mods côté client comme les minimaps, les shaders, les outils de performance et le chat vocal sont autorisés sur MatchaSMP. Les mods de triche comme X-ray ou freecam sont interdits, et un anti-triche tourne sur le serveur.

### MatchaSMP est-il un serveur pay-to-win ?

Non. La boutique ne vend que des améliorations de confort et des cosmétiques. Les rangs donnent des avantages de confort, comme plus de maisons et de rangées de coffre de l'End, pas de puissance.
