Gilly SMP crossplay: Java, Bedrock and console in one world

Gilly SMP runs one shared world for Java, Bedrock and console players. This guide covers how the platforms connect, how to keep progress when you play on more than one, and what changes visually on Bedrock.

9 answersFull wiki →

Playing together across platforms

Can Java and Bedrock players play together on Gilly SMP?

Yes. Java, Bedrock and console players all share one world on Gilly SMP. You can build, trade and explore together regardless of platform, because the server runs a custom crossplay setup rather than separate worlds.

Can Xbox, PlayStation and Switch players join Gilly SMP?

Yes. Console players add GillySMP as a friend and then join from the console's Friends tab. A console online subscription is required, and that subscription is provided by the console maker, not by Gilly SMP. See the Getting started section.

Can I use the same inventory and XP on Java and Bedrock?

Yes, once you link the accounts. Run /linkaccount on one account and follow the instructions to link it to the other. The two accounts then share one player profile, so inventory, XP and progress follow you between platforms. Use /unlinkaccount to undo the link.

Why does my Bedrock name start with an underscore?

Bedrock names get a _ prefix on Gilly SMP, and spaces become underscores, so they never clash with Java names. The prefix is the same on the proxy and on the server, so you keep one consistent name everywhere you play.

Are there any Minecraft servers with Java and Bedrock crossplay in Europe?

Gilly SMP is hosted in France and is the only EU-hosted Matcha Flavoured server with Java–Bedrock crossplay. Java, Bedrock and console players share one world. /linkaccount syncs inventory and XP between accounts, and a Bedrock-compatible resource pack is in development so Bedrock will eventually see the custom textures too.

Resource packs and mods

Do Bedrock players need the Gilly SMP resource pack?

No. The Gilly SMP resource pack is a Java pack and Bedrock cannot load it. Bedrock players always see vanilla textures and some raw item keys, but every item and mechanic still works the same way.

What happens if I don't accept the resource pack on Java?

The server sends the Gilly SMP resource pack automatically when you join — just accept the prompt. If you don't, custom items look like vanilla items and some show raw text names. You can rejoin and accept it, or check Options → Resource Packs.

Are mods allowed on Gilly SMP?

Client-side mods for performance, minimaps, shaders and voice chat are fine, and no mods are required to play. Cheat mods such as X-ray, freecam and hacked clients are banned; the server runs anti-cheat and staff may ask a suspected player to run a verification mod.

Do I need a paid Minecraft account to join?

Yes. Gilly SMP runs in online mode, so a legitimate Minecraft account is required. Cracked or offline launchers cannot connect. There is no whitelist, so any legitimate account can join.
