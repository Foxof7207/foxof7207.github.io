What Is Matcha Flavoured? A Minecraft Survival Datapack Explained

Matcha Flavoured is a Minecraft datapack that reworks survival progression for casual players, and you may also see it spelled Matcha Flavored. These answers explain what it changes in plain language. MatchaSMP runs it as a crossplay server.

10 answersFull wiki →

The datapack

What is the Matcha Flavoured datapack?

Matcha Flavoured is a Minecraft Java datapack with a companion resource pack. It reworks survival progression so casual players can gather resources at a pace closer to technical players, and it makes death less punishing. MatchaSMP runs it server-side, so you don't need to install it yourself.

Is Matcha Flavoured a mod or a datapack?

It is a datapack with a companion resource pack, not a client mod you install. On MatchaSMP it runs on the server, so Java players only need Minecraft 26.3 and the server resource pack, which is sent automatically.

Why do people write Matcha Flavored with an o?

Both Matcha Flavoured and Matcha Flavored refer to the same datapack. Players search for both spellings, so the guides and servers listed here cover either one.

What changes in survival

Does Matcha Flavoured remove hunger?

Yes. Hunger is effectively gone: you don't starve, and food is about its effects instead of filling a bar. On MatchaSMP there are about 50 new foods, and healing comes from food effects, potions and special items.

Does Matcha Flavoured turn off natural health regeneration?

Yes. Natural health regeneration is off, so you heal by eating foods with healing effects, drinking potions or using special items. On MatchaSMP this is one of the core rules.

How does death work in Matcha Flavoured?

On MatchaSMP you keep your inventory and XP, but each death removes one maximum heart. The server runs Easy, so your maximum never drops below 10 hearts. Crystal Hearts restore maximum hearts up to 30.

Does Matcha Flavoured need mob farms?

It is designed so you don't need them. Progression rewards exploration, cooking, fishing and trading instead of technical grinders. On MatchaSMP there are no mob farms, XP farms or villager trading halls.

Playing it

Which alloys does Matcha Flavoured add?

The rework adds alloys smithed onto base metals: Hepatizon and Shakudo on copper, Steel on iron, and Electrum and Adamant on diamond. MatchaSMP also has mattocks and dolabras, which are two-in-one tools.

Which Minecraft version does Matcha Flavoured use on MatchaSMP?

MatchaSMP runs Matcha Flavoured on Minecraft Java 26.3. Java players need 26.3 to connect to play.matchasmp.eu, and Bedrock players connect on port 19132. Check the Getting started page for the current version.

Can Bedrock players play Matcha Flavoured?

Yes on MatchaSMP. Bedrock can't load Java resource packs, so Bedrock players see vanilla textures and some raw keys on custom items, but the rework's rules still apply to them.
