# Can Java and Bedrock Players Share One Minecraft World? Crossplay Explained

Crossplay means Minecraft players on Java, Bedrock, Xbox, PlayStation and Switch can explore the same world together. This guide covers how that works in practice, from linking accounts to what each platform can see. MatchaSMP is the worked example.

## Playing together across platforms

### Can Java and Bedrock players play in the same Minecraft world?

Yes. On MatchaSMP, Java, Bedrock, Xbox, PlayStation and Switch players all share one world. Java uses `play.matchasmp.eu`, and Bedrock uses the same address on port **19132**.

### Can I use the same commands on Bedrock and console as on Java?

Almost. Bedrock and console players get most commands as buttons in `/menu`, including homes, teleport requests, the ender chest, orders, trades and private messages. Clickable chat messages don't work on Bedrock, which is a Bedrock limitation.

### Can I use voice chat on a crossplay server if I play on console?

Voice chat is optional. Java players can install the Simple Voice Chat mod, but Bedrock and console can't use it, so it's never required to play.

## Accounts and progress

### How do I link a Java and a Bedrock account so they share progress?

Run `/linkaccount` on one account and follow the instructions to link it to the other. Once linked, the two accounts share one player profile. `/unlinkaccount` undoes it.

### Why does my Bedrock username have an underscore in front of it?

Bedrock usernames get a `_` prefix and spaces are turned into underscores. That stops them clashing with Java names, and the prefix is the same on the proxy and the server, so you keep one name everywhere.

### Can Bedrock players see custom textures from the Java resource pack?

No. Bedrock can't load Java packs, so Bedrock players see vanilla textures and sometimes raw keys on custom items. Everything still works, but the custom look only appears on Java.

## Mods and fair play

### Which mods are allowed on a Minecraft crossplay server?

Client-side mods such as minimaps, shaders, performance tools and voice chat are fine on MatchaSMP. Cheat mods such as X-ray or freecam are banned, and an anti-cheat runs on the server.

### Is MatchaSMP pay-to-win?

No. The store only sells quality-of-life items and cosmetics. Ranks give convenience perks such as more homes and ender chest rows, not power.
