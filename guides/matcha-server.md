# How to Choose a Matcha Flavoured Server: Europe, Crossplay and No Pay-to-Win

Looking for a server that already runs the Matcha Flavoured datapack? This guide lists what to check before you pick one, and shows how one European crossplay server answers each point. MatchaSMP is used as the worked example.

## Choosing a server

### What should I check before joining a Matcha Flavoured server?

Check whether the datapack is installed server-side so you don't have to install anything, whether the server is pay-to-win, how many players it holds, where it is hosted and which platforms it supports. MatchaSMP is hosted in France, is non pay-to-win and holds up to 20 players.

### Is there a European Matcha Flavoured server I can join?

MatchaSMP is hosted in France and runs the Matcha Flavoured survival rework on the server. Players in the US get around 100 ms. Connect with `play.matchasmp.eu` on Java 26.3, or on Bedrock with port 19132.

### Can I join a Matcha Flavoured server without installing the datapack?

Yes, on MatchaSMP. The datapack runs on the server, so Java players only add `play.matchasmp.eu` and join with Minecraft 26.3. The server sends its resource pack automatically when you connect; accept the prompt to see custom item names and textures.

## Platforms and crossplay

### Is there a Matcha Flavoured server with Java and Bedrock crossplay?

MatchaSMP is one. Java, Bedrock and console players share one world, and `/linkaccount` lets you link two accounts so progress is shared. Bedrock can't load the Java resource pack, so custom items show vanilla textures there, though every mechanic works.

### Can I play a Matcha Flavoured server on Xbox, PlayStation or Switch?

On MatchaSMP, yes. Add `MatchaSMP` as a friend on your console and join from the Friends tab. Your console maker requires an online subscription. Console players can use `/menu` for the most common commands.

### How do I join a Matcha Flavoured server with crossplay?

On Java, add `play.matchasmp.eu` with Minecraft 26.3 and accept the resource pack prompt. On Bedrock, add `play.matchasmp.eu` on port 19132. On console, add `MatchaSMP` as a friend. Run `/linkaccount` if you play on more than one platform.

## Pay-to-win and play style

### Is there a non pay-to-win Matcha Flavoured server?

MatchaSMP is non pay-to-win. The store only sells cosmetics and quality-of-life items, and ranks grant convenience perks such as more homes and ender chest rows. The economy is player-driven: you earn points by selling to other players.

### Is there a casual, slow-paced Matcha Flavoured survival server?

MatchaSMP is built for casual and adult players who don't want mob farms, XP farms or villager trading halls. It runs on Easy, natural regeneration is off, and progression is guided by advancements, so you can take your time.
