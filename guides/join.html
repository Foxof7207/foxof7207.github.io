How to Join Gilly SMP: Addresses, Ports, Console and Account Rules

Gilly SMP is a slow-paced survival SMP where Java, Bedrock and console players share one world. This hub covers everything you need to connect, from server addresses and versions to accounts, whitelist rules and the resource pack.

15 answersFull wiki →

Server addresses by platform

What is the Java server address for Gilly SMP and which Minecraft version do I need?

Connect with Minecraft Java using the address mc.gillyb.net. Java version 26.3 is required, so older versions can't join. Java, Bedrock and console players all share the same world.

What address and port do I use to join Gilly SMP on Bedrock?

On Bedrock, use the address mc.gillyb.net with port 19132. On Windows, Android, iPhone and iPad, the Add to Minecraft button on the Bedrock card opens the game with the server already added.

How do I join Gilly SMP from Xbox, PlayStation or Switch?

Add GillySMP as a friend on your console and join from the Friends tab. The console maker requires an online subscription to play online, so you need one to connect. Once in, you share one world with Java and Bedrock players.

Can Java, Bedrock and console players play together on Gilly SMP?

Yes. Java, Bedrock, Xbox, PlayStation and Switch players all join the same world on Gilly SMP. Bedrock names get an underscore prefix, with spaces turned into underscores, so they never clash with Java names, and you keep one name everywhere.

Which crossplay survival server can I join from Europe?

Gilly SMP is hosted in France and runs one shared world for Java, Bedrock and console players. It is a slow, non pay-to-win survival SMP running the Matcha Flavoured rework, with no whitelist and a 20-player cap. Java connects to mc.gillyb.net on 26.3; Bedrock uses port 19132.

Is there a Matcha Flavoured server I can join without installing the datapack?

Yes. Gilly SMP runs the Matcha Flavoured rework on the server, so Java players only need Minecraft 26.3 and the server address mc.gillyb.net. The resource pack is sent automatically when you join; accept it to see custom item names and textures.

Accounts and access

Do I need a paid Minecraft account to join Gilly SMP?

Yes. Gilly SMP runs in online mode, so you need a legitimate, paid Minecraft account. Cracked or offline launchers cannot connect.

Is there a whitelist on Gilly SMP?

No. There is no whitelist on Gilly SMP: anyone with a legitimate account can join. The server allows up to 20 players at a time and runs on Easy difficulty.

Why can't my cracked or offline launcher connect to Gilly SMP?

Because the server runs in online mode. Only legitimate paid Minecraft accounts are accepted, so cracked launchers and offline-mode clients are refused. Use a paid account at mc.gillyb.net on Java 26.3 instead.

Do console players need an online subscription to join Gilly SMP?

Yes. The console maker requires an online subscription to play online. To join Gilly SMP from Xbox, PlayStation or Switch you also add GillySMP as a friend and enter from the Friends tab.

Resource pack and mods

Do I need to download the Gilly SMP resource pack?

No download is needed. The Gilly SMP resource pack is sent automatically when you join on Java: just accept the prompt. The server adds hundreds of custom items, and the pack gives them their proper textures and names.

What happens if I don't accept the resource pack on Gilly SMP?

Without the resource pack, items look vanilla and some have raw text names. Rejoin and accept the prompt, or enable it under Options → Resource Packs. On Bedrock the pack can't be loaded, so vanilla textures and some raw keys are expected, but everything still works.

Can I join Gilly SMP without installing any mods?

No mods are required to join or play. Client-side mods for performance, minimaps, shaders and voice chat are fine, but cheat mods such as X-ray, freecam and hacked clients are not allowed. The server runs anti-cheat and staff may request a verification mod if they suspect cheating.

Your first minutes on the server

What should I do right after joining Gilly SMP?

Open your advancements with L: the survival rework uses them as a step-by-step guide. Once you have a base, set a home with /sethome base, and /spawn brings you back to spawn at any time. Natural health regeneration is off, so the early game is slower than vanilla.

If I play on Java and Bedrock, can I keep the same progress?

Yes. Run /linkaccount on one account and follow the instructions to link it to the other; /unlinkaccount undoes it. Once linked, the two accounts share one player profile, so your progress carries across Java and Bedrock.
