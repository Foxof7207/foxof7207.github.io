How to Join a Minecraft Survival Server From Java, Bedrock or Console

Want to play Minecraft survival with friends who use a different device? This guide explains how Java, Bedrock and console players connect to one shared crossplay server. MatchaSMP is used as the worked example.

9 answersFull wiki →

Server addresses by platform

Which address and port do Bedrock players use to join a Minecraft server?

On MatchaSMP, Bedrock players use the address play.matchasmp.eu with port 19132. On Windows, Android, iPhone and iPad, the Add to Minecraft button on the server page opens the game with the server already added.

Which Minecraft Java version do I need to join a survival server?

MatchaSMP requires Minecraft Java 26.3, so older versions can't connect. Use the address play.matchasmp.eu, and Java, Bedrock and console players all share the same world.

How do I join a Minecraft server from Xbox, PlayStation or Switch?

Add MatchaSMP as a friend on your console and join from the Friends tab. Your console maker requires an online subscription to play online, so you need one to connect.

Accounts and access

Can I join a Minecraft server with a cracked or offline launcher?

No. MatchaSMP runs in online mode, so only legitimate paid accounts can join. Cracked and offline launchers can't connect.

Do I need to be on a whitelist to join a Minecraft server?

Not on MatchaSMP. There is no whitelist, so anyone with a legitimate account can join. The server holds up to 20 players.

Why does my Bedrock name start with an underscore on a Java server?

Bedrock names get a _ prefix and spaces become underscores, so they never clash with Java names. The prefix is the same on the proxy and on the server, so you keep one name everywhere.

Before your first session

Do I need a resource pack to play on a Minecraft server with custom items?

On Java, yes. MatchaSMP sends its resource pack automatically when you join, so just accept the prompt. Without it, custom items look vanilla and some have raw text names. Bedrock can't load Java packs, so Bedrock players see vanilla textures, but everything still works.

Which mods can I use on a Minecraft survival server?

Client-side mods such as performance tools, minimaps, shaders and voice chat are fine on MatchaSMP. Cheat mods like X-ray, freecam or hacked clients are not allowed, and the server runs anti-cheat.

What should I do first after joining a survival server?

Open your advancements with L on Java, since the survival rework uses them as a step-by-step guide. Once you have a base, set a home with /sethome base, and /spawn takes you back at any time.
