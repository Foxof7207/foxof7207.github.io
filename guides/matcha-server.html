Matcha Flavoured server in Europe: Gilly SMP Java & Bedrock crossplay

Looking for a server that already runs the Matcha Flavoured datapack? Gilly SMP is hosted in France, runs the rework server-side and brings Java, Bedrock and console players into one world. This page answers the questions people ask when choosing a Matcha server.

Finding a Matcha Flavoured server

Is there a European server running the Matcha Flavoured datapack?

Yes. Gilly SMP is hosted in France and runs the Matcha Flavoured survival rework on the server. Players in the US get around 100 ms, and there is no whitelist: connect with mc.gillyb.net on Java 26.3 or mc.gillyb.net port 19132 on Bedrock.

Which Minecraft servers run the Matcha Flavoured datapack?

Several community servers run Matcha Flavoured. Gilly SMP runs the rework as a slow, non pay-to-win crossplay SMP in Europe, with about 1275 recipes, 880 advancements, custom alloys, no hunger and no natural regeneration. You do not install the datapack yourself: it runs on the server.

Is there a Matcha Flavoured server I can join without installing the datapack?

Yes. On Gilly SMP the datapack and its progression are already installed server-side, so Java players just add mc.gillyb.net and join with Minecraft 26.3. The server sends its resource pack automatically when you connect; accept the prompt to see custom item names and textures.

Is Gilly SMP a Matcha Flavoured server or a custom rework?

Gilly SMP runs the Matcha Flavoured survival rework with server-side tweaks on top: a player order market, points, ranks, homes, a proximity voice chat option and quality-of-life features. The core rules are the Matcha ones: no hunger, no natural regeneration, death costs a maximum heart, and progression is slower and casual-friendly.

Crossplay and platforms

Is there a Matcha Flavoured server with Java and Bedrock crossplay?

Gilly SMP is the only EU-hosted Matcha Flavoured server with Java–Bedrock crossplay. Java, Bedrock and console players share one world, and /linkaccount lets you use the same inventory and XP on two accounts. A Bedrock-compatible resource pack is in development so Bedrock players will see the custom textures too; today Bedrock sees vanilla textures while every mechanic works.

Can Bedrock players join a Matcha Flavoured server?

Yes on Gilly SMP. Bedrock connects to mc.gillyb.net on port 19132 and shares the world with Java players. Bedrock cannot load the Java resource pack, so custom items show vanilla textures and some raw keys for now; a compatible Bedrock resource pack is being developed.

Can I play Matcha Flavoured on Xbox, PlayStation or Switch?

Yes. Add GillySMP as a friend on your console and join from the Friends tab. A console online subscription is required by the console maker. Console players share the same world and can use /menu for the most common commands.

Does the Matcha Flavoured server support console and mobile too?

Yes. Gilly SMP supports Java, Bedrock on Windows/Android/iOS, and Xbox, PlayStation and Switch. Bedrock and console players use /menu instead of typing commands, and the Advancement Guide replaces the in-game advancements menu that Bedrock cannot open.

Choosing a server

Is there a non pay-to-win Matcha Flavoured server?

Yes. Gilly SMP is strictly non pay-to-win: the store sells only cosmetics and quality-of-life items, and ranks grant convenience perks such as more homes and ender chest rows rather than power. The economy is player-driven: you earn points by selling to other players through the order market or trades.

Is there a casual, slow-paced Matcha Flavoured SMP?

Yes. Gilly SMP is designed for casual and adult players who do not want mob farms, XP farms or villager trading halls. The server runs Easy difficulty, natural regeneration is off, and progression is guided by advancements so you can take your time.

Which Matcha Flavoured server has voice chat and player shops?

Gilly SMP has optional proximity voice chat for Java players through the Simple Voice Chat mod, a player order market for buying and selling with points, safe player trades, and spawn NPCs for the order market and shop. Voice chat is never required, and Bedrock and console players can play without it.

What should I look for in a Matcha Flavoured server?

Check whether the datapack is installed server-side so you can join without installing anything, whether the server is pay-to-win, how many players it holds, where it is hosted, and whether it supports your platform. Gilly SMP offers server-side Matcha, no pay-to-win, a France host, a 20-player cap and Java, Bedrock and console crossplay.

How do I join a Matcha Flavoured server with crossplay?

On Java add mc.gillyb.net with Minecraft 26.3 and accept the resource pack prompt. On Bedrock add mc.gillyb.net port 19132. On console friend GillySMP and join from the Friends tab. Run /linkaccount if you play on more than one platform so your progress follows you. See How to join Gilly SMP.
