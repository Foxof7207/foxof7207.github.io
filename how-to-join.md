## Joining steps
1. Read the whitelist requirements below.
2. Join the Discord server or contact a helper for whitelist access.
3. Complete any required application details and wait for approval.

## 📝 Whitelist Requirement

::: warning Whitelist Only
Gilly-SMP is a **whitelist only** server, you must be added to the whitelist before you can join.
:::
